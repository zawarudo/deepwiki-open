# Task 001: Add query-embedder adapter for FAISSRetriever expectations

## Description

Create embedder wrapper to normalize provider response formats into consistent tuple (embedding, metadata) that FAISS expects. This addresses the unpacking error in RAG operations where different embedding providers return different response formats.

## Phase

1.2

## Acceptance Criteria

- [ ] Create query embedder adapter that handles multiple provider formats
- [ ] Support OpenAI dict format response normalization
- [ ] Support Gemini numpy arrays response normalization  
- [ ] Support Ollama dict format response normalization
- [ ] Support OpenRouter direct lists response normalization
- [ ] Return consistent tuple (embedding, metadata) format for FAISS
- [ ] All provider formats tested and working
- [ ] Integration tests pass with FAISSRetriever

## Technical Details

The embedder wrapper should:
- Act as an adapter between embedding providers and FAISS expectations
- Normalize different response formats into consistent tuples
- Handle provider-specific response structures:
  - OpenAI: Dictionary with 'data' key containing embeddings
  - Gemini: Direct numpy array responses
  - Ollama: Dictionary format with embedding data
  - OpenRouter: Direct list format
- Maintain metadata consistency across providers
- Provide error handling for malformed responses

## Dependencies

- Current embedding provider implementations
- FAISS retriever expectations
- Provider-specific response format documentation
