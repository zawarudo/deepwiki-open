# Task: Add Batch-Level Dimension Consistency Check

## Description
Currently, the Google Embedding Client validates individual embeddings but lacks batch-level dimension consistency validation. This can lead to mixed dimensions within a batch causing subtle bugs and late detection of dimension inconsistencies that could crash downstream FAISS operations.

## Acceptance Criteria
- [ ] Batch-level validation ensures all embeddings have consistent dimensions
- [ ] Clear error reporting for dimension inconsistencies within batches
- [ ] Validation occurs after collecting all embeddings in the batch
- [ ] Performance impact is minimal (single pass validation)
- [ ] Proper handling of null embeddings in dimension checks

## Technical Details
- Implementation approach: Add validation after embedding collection loop completes
- Key considerations: 
  - Must handle null embeddings gracefully (filter them out before dimension check)
  - Use set comparison for efficient duplicate dimension detection
  - Provide clear error message showing all detected dimensions
- Code locations/files affected:
  - `api/google_embedding_client.py` - Add after embedding collection loop

### Required Implementation
```python
# After collecting all embeddings
dimensions = [len(e) for e in successful_embeddings if e is not None]
if len(set(dimensions)) > 1:
    raise EmbeddingGenerationError(
        f"Inconsistent dimensions in batch: {set(dimensions)}"
    )
```
