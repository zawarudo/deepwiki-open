# Task: EMERGENCY FIX - Stop empty vector creation in GoogleEmbeddingClient

## ⚠️ CRITICAL SYSTEM FAILURE

**THE APPLICATION IS COMPLETELY NON-FUNCTIONAL**
- ALL 923 documents have empty embeddings
- FAISS cannot create index from empty vectors
- RAG/Chat system crashes with 500 errors
- Users cannot use ANY features that require embeddings

## Root Cause Identified

The GoogleEmbeddingClient in `api/google_embedding_client.py` creates empty arrays `[]` when API calls fail, instead of properly handling errors. This silently corrupts the entire embedding database.

### Specific Lines Creating Empty Vectors:
```python
# Line 119 - When API call fails
except Exception as e:
    embeddings.append(Embedding(embedding=[], index=i))  # BUG: Creates empty vector

# Line 127 - When JSON parsing fails  
except (KeyError, ValueError) as e:
    embeddings.append(Embedding(embedding=[], index=i))  # BUG: Creates empty vector

# Lines 143-144 - When count mismatch occurs
for i in range(batch_size):
    embeddings.append(Embedding(embedding=[], index=i))  # BUG: Creates empty vector
```

def _validate_embedding(self, embedding: List[float], expected_dim: int = 768) -> bool:
    """Validate embedding has correct dimensions."""
    if not embedding:
        raise ValueError("Empty embedding vector")
    if len(embedding) != expected_dim:
        raise ValueError(f"Invalid embedding dimension: {len(embedding)}, expected {expected_dim}")
    return True
