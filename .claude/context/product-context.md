# Product Context

## Product Definition

**DeepWiki-Open** is an AI-powered documentation generator that automatically creates comprehensive, interactive wikis for any GitHub, GitLab, or BitBucket repository. It transforms codebases into navigable, well-structured documentation with visual diagrams and intelligent Q&A capabilities.

## Target Users

### Primary Users
1. **Software Development Teams**

   - Use Case: Generate comprehensive project documentation automatically
   - Value: Reduced documentation burden, improved knowledge transfer

   - Need: Keep documentation synchronized with code
   - Use Case: Auto-generate and update project wikis
   - Value: More time for coding, better contributor experience

3. **Technical Writers**
   - Need: Understand complex codebases quickly
   - Use Case: Generate initial documentation drafts

4. **DevOps Engineers**

3. **Students & Educators**

## Core Functionality

### 1. Automatic Wiki Generation
- **Input**: Repository URL (GitHub/GitLab/BitBucket)
- **Process**: AI analysis of code structure and relationships
- **Output**: Structured wiki with navigation

### 2. Code Analysis & Understanding
- **Structure Analysis**: Identify modules, classes, functions
- **Dependency Mapping**: Trace relationships between components
- **Pattern Recognition**: Identify design patterns and architectures

### 3. Visual Diagram Generation
- **Architecture Diagrams**: System overview with Mermaid
- **Flow Charts**: Process and data flow visualization
- **Relationship Maps**: Component interaction diagrams

### 4. Interactive Q&A (Ask Feature)
- **RAG-Powered**: Retrieval-Augmented Generation for accuracy
- **Context-Aware**: Understands repository context
- **Natural Language**: Plain English questions and answers

### 5. DeepResearch Feature
- **Multi-Turn Analysis**: Thorough investigation of topics
- **Cross-Reference**: Links related concepts
- **Comprehensive Reports**: Detailed research outputs

### 6. Multi-Provider AI Support
- **Google Gemini**: Advanced language understanding
- **OpenAI GPT**: Industry-standard AI models
- **OpenRouter**: Access to multiple models
- **Ollama**: Local, privacy-focused processing
- **Azure OpenAI**: Enterprise-grade deployment
